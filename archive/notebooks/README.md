# Archived notebooks

These directories preserve historical Gene2Wire notebook releases for
provenance. They may carry older core pins, filenames, defaults, or outputs and
are not current experiment entry points.

Do not regenerate or edit archived notebooks in place. Use the output-cleared
stable filenames indexed in [`notebooks/README.md`](../../notebooks/README.md)
for new runs. If a historical notebook must be corrected, preserve the original
and document the correction as a new canonical release.
